# Mini-Projet XML/XSD/XQuery — Club Info_Tech

## Description
Projet de gestion d'un club informatique utilisant XML, XSD et XQuery.

## Contenu
- `club.xml` — Document XML des données du club
- `club.xsd` — Schéma de validation XSD
- `requetes.xq` — 5 requêtes XQuery (liste membres, concours, scores, vainqueurs, filtre)
- `updates.xq` — 3 mises à jour XQuery (insertion, modification, suppression)
- `captures/` — Captures d'écran des résultats
- `web/` — Site web PHP connecté à BaseX

## Technologies utilisées
- XML / XSD
- XQuery (BaseX)
- PHP / XAMPP
